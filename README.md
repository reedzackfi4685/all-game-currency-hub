## Overview

All Game Currencies creates a unified virtual economy for currencies originating in different games. Each participating game is evaluated and given an exchange rate, allowing players to keep track of their stored currency and explore its potential use across the wider game network.

The experience is aimed at players who want currency accumulation to contribute to persistent upgrades and reward progression. Earning is subject to limits designed to make automated farming less effective, while longer sleep periods can provide additional bonuses.

---

## Core Capabilities

- Evaluates games and calculates exchange values for their currencies.
- Stores game currency in a common shared economy.
- Makes eligible currency available for use between participating games.
- Includes permanent upgrades that support continued progression.
- Uses earning caps to discourage bot-based farming.
- Grants bonuses when sleep periods exceed four hours.
- Connects game-specific rewards with a cross-game currency model.
- Runs through a web interface in the browser.
